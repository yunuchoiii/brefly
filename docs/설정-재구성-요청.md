# 설정 탭 재구성 요청 프롬프트

아래 `---` 사이를 그대로 복사해 ChatGPT / Claude 에 붙여넣으세요.
**기존 탭 구성은 일부러 넣지 않았습니다** — 알려 주면 그 틀을 그대로 따라오기 때문입니다.

---

macOS 메뉴바 앱 **Brefly(브레플리)** 의 설정 창을 어떤 탭으로 나눌지 정해 줘.

## 이 앱이 하는 일

단축키를 누르고 말하면, 받아 적은 것을 AI 가 정리해서 **커서 자리에 바로 넣어 주는** 앱이야.
메모장이든 메신저든 지금 타이핑하던 자리에 그대로 들어가. 창을 따로 열 필요가 없어.

여기에 **회의록** 기능이 붙었어. 대면 회의(이 맥의 마이크), 화상 회의(내 목소리 + 스피커로
나오는 상대 목소리), 이미 가지고 있는 녹음 파일 — 셋 중 하나로 시작하면 받아 적고
"결정된 것 / 할 일 / 논의한 것" 같은 꼴로 정리해 줘.

쓰는 사람은 **개발자가 아니야.** 기획자·디자이너·학생처럼 회의를 많이 하는 사람들이고,
"API", "백엔드" 같은 말을 모른다고 보고 설계했어. 설정 문구도 전부 '~합니다'체 평어다.

## 설정 창에 있는 것 전부

순서에 의미는 없어. 지금 어떻게 묶여 있는지는 일부러 안 알려 줄게 — 백지에서 봐 줘.

1. 받아쓰기를 시작·종료하는 단축키를 직접 정하기 (칸을 누르고 조합을 입력)
2. 받아쓰기 단축키를 미리 정해진 조합 중에서 고르기 (fn⌃ 같은 추천 조합 목록)
3. 클립보드에 자동 복사 (켜기/끄기)
4. 지금 상태 진단 — 권한 4종, 인식 언어, 키 유무를 한 화면에 보여 주는 버튼
5. 회의록을 얼마나 자세히 쓸지 (1~5단계 슬라이더, 기본 3)
6. 커서 위치에 자동 붙여넣기 (켜기/끄기 · 손쉬운 사용 권한이 필요)
7. Gemini API 키 입력·확인
8. 로그인할 때 앱 자동 실행 (켜기/끄기)
9. 대면 회의 녹음을 시작·종료하는 단축키
10. 정리가 끝나면 결과 창 띄우기 (켜기/끄기)
11. 음성 인식을 애플 서버에서 처리 (켜기/끄기 · 끄면 인터넷 없이 되지만 덜 정확)
12. 로그 파일 열기 (버튼)
13. 화면 모드 — 밝게 / 어둡게 / 시스템 따라가기
14. 받아쓰기를 정리할 AI 모델 고르기 (AUTO, 또는 회사와 등급을 직접)
15. 붙여넣기 테스트 — 3초 뒤 커서 자리에 글자를 넣어 보는 버튼
16. 녹음 중 다른 소리 줄이기 (켜기/끄기 · 음악·영상 소리를 낮춤)
17. ChatGPT API 키 입력·확인
18. 말을 멈추면 자동으로 요약 (켜기/끄기 + 몇 초 뒤에 할지)
19. 처음 설정 안내를 다시 보기 (버튼)
20. 회의록을 요약할 AI 모델 고르기 (받아쓰기와 따로 고름)
21. 새 버전이 있는지 지금 확인 (버튼)
22. 정리 스타일 — 기본 정리 / 격식체(보고·이메일) / 구어체 유지(메신저) / 원문 최소 손질 / 핵심 요약
23. 화상 회의 녹음을 시작·종료하는 단축키
24. 인식 언어 고르기 (한국어·영어 등)
25. AI 로 정리하기 (끄면 받아 적은 원문을 그대로 넣음)
26. Claude API 키 입력·확인
27. 실패했을 때 시스템 알림 띄우기 (켜기/끄기)
28. Dock 에 앱 아이콘 표시 (켜기/끄기)
29. 녹음을 시작·종료할 때 알림음 (켜기/끄기)
30. 하이라이트 단축키 — 회의 녹음 중 누르면 그 대목이 회의록에 꼭 들어감
31. 바뀐 점(릴리스 노트) 보기 (버튼)
32. 붙여넣기 후 클립보드를 원래대로 되돌리기 (켜기/끄기)
33. AI 모델 연결 테스트 — 짧은 문장을 실제로 정리해 보는 버튼
34. 주로 어디에 쓰는지 고르기 (분야·상황을 고르면 그 분야 용어를 받아쓰기가 잘못 들어도 바로잡음)
35. 앱을 실행할 때 새 버전을 자동으로 확인 (켜기/끄기)
36. Gemini 에서 쓸 세부 모델 고르기 (모델 이름 목록)
37. 시스템 설정의 '받아쓰기' 화면 열기 (버튼 · 꺼져 있으면 인식이 안 됨)
38. 손쉬운 사용(접근성) 권한 화면 열기 (버튼 · 자동 붙여넣기에 필요)
39. 이 키로 쓸 수 있는 Gemini 모델 목록 조회 (버튼)
40. 업데이트 설치 방법 안내와 다운로드 (버튼)
41. 후원하기 — GitHub Sponsors 링크 (버튼)

## 정해 줬으면 하는 것

1. **탭을 몇 개로, 무슨 이름으로** 나눌지. 이름은 한글 한두 단어로.
2. **41개를 전부** 어느 탭에 넣을지. 하나도 빠뜨리지 말고, 한 항목은 한 탭에만.
3. 탭 안에서의 **묶음(소제목)과 순서**. 자주 건드리는 것이 위로 오게.
4. 각 탭을 그렇게 묶은 **이유 한 줄씩.**

## 지켜야 할 것

- 탭 이름과 소제목에 **전문 용어를 쓰지 마.** 'API', '백엔드', '엔진' 같은 말은 안 돼.
  (단, 'Gemini'·'ChatGPT'·'Claude' 처럼 사용자가 가입해서 키를 받아 오는 서비스 이름은 써도 돼.)
- 테스트·진단·로그처럼 **평소엔 안 쓰는 것**과, 매일 건드리는 것이 섞이지 않게 해 줘.
- 받아쓰기와 회의록은 **쓰는 상황이 다르다.** 받아쓰기는 몇 초짜리라 커서에 바로 꽂히는 게
  중요하고, 회의록은 몇십 분짜리라 잘 정리되는 게 중요해. 이걸 갈라야 할지 합쳐야 할지도 봐 줘.
- 한 탭에 항목이 너무 몰리거나, 반대로 두세 개뿐인 탭이 생기지 않게.
- 처음 쓰는 사람이 **무엇부터 건드려야 하는지** 보이면 좋겠어.

맞다고 생각하는 안 하나를 정해서 주고, 고민한 지점이 있으면 그것도 같이 적어 줘.
