Brefly(브레플리) macOS 메뉴바 앱의 시안을 이어서 작업해 줘.
기존 프로젝트 `33c3d303-b550-452a-a846-8e568db7e5a0` 의 `Voice Summary App.dc.html` 과
`Brefly Onboarding.dc.html` 이 기준이야. 그 톤과 컴포넌트를 그대로 이어 가되,
아래 세 가지를 반영해 줘.

## 이 앱이 하는 일

말하면 AI 가 정리해서 **커서 위치에 바로 넣어 주는** 맥 메뉴바 앱이야.
`fn⌃` 를 누르면 녹음이 시작되고, 말을 마치고 다시 누르면 정리된 글이 커서 자리에 붙어.
이번에 **녹음 파일로 회의록을 만드는 기능**이 새로 들어가.

## 1. 지난 시안 이후 바뀐 것 (확인받고 싶은 부분)

시안에 없던 것들이 코드에 들어가 있어. 이번 시안에 같이 넣어서 봐 줬으면 해.

- **핵심 요약 기능**이 생겼어. 말한 걸 다듬는 게 아니라 **불릿 목록으로 요약**해 줘.
  정리 스타일이 다섯 개가 됐고, 설정에서 **라디오 그룹**으로 고르게 돼 있어
  (드롭다운이었는데 사람들이 기능이 있는 줄 몰라서 바꿨어):
  - 기본 정리
  - 격식체 (보고·이메일)
  - 구어체 유지 (메신저)
  - 원문 최소 손질
  - **핵심 요약 (불릿 목록)**
- 핵심 요약 **켜고 끄는 토글**이 있고, 색은 시스템 파랑이 아니라 테마 코랄이야.
- 녹음 시작 버튼 **안쪽 오른쪽**에 단축키 키캡(fn⌃)이 들어가 있어. 버튼 밖에 있던 걸 안으로 옮겼어.
- 설정에 **로그인 시 자동 실행** 항목이 있고, 설치 마법사 마지막 화면에서도 체크박스로 물어봐.
- 앱이 **스스로 업데이트**를 받아. 새 버전이 있으면 알림창이 뜨고 "설치"만 누르면 끝나.

이 항목들이 지금 시안 체계와 잘 맞는지 봐 주고, 어긋나면 고쳐 줘.

## 2. 새로 필요한 화면 — 회의록 (이번 요청의 핵심)

녹음 파일을 골라 넣으면 회의록을 만들어 주는 기능이야.
메뉴바 아이콘 오른쪽 클릭 → **"녹음 파일로 회의록 만들기…"** 로 시작해.

동작은 이래:

1. 파일 고르기 (macOS 기본 열기 창)
2. 받아쓰기 — 기기 안에서 도는 모델이 처리해. 인터넷에 안 보내.
3. 요약 — 이때만 클라우드 AI 를 써.
4. 결과를 녹음 파일 옆에 `.md` 로 저장하고 Finder 로 보여 줌. 클립보드에도 복사.

**시간이 걸려.** 20분 녹음이면 약 70초, 35분이면 약 110초야.

### 2-1. 처리 중 화면 ← 제일 급해

지금은 **메뉴를 열어야만** 진행 상황이 보여. 메뉴를 닫으면 아무 표시가 없어서
사용자가 **멈춘 줄 알고 포기해.** 1~2분 동안 "지금 돌아가고 있다"를 계속 보여 줄 방법이 필요해.

보여 줄 내용은 이 정도야:

- 지금 어느 단계인지 — "받아쓰는 중" → "요약하는 중"
- 얼마나 걸릴지 짐작할 거리 (진행률이나 경과 시간)
- 취소할 방법

**세 가지 방향을 다 그려 주고 어느 쪽이 나은지 의견을 줘.**

- (가) 메뉴바 아이콘 자체에 진행 표시 — 가장 방해가 적지만 정보가 거의 안 들어가
- (나) 팝오버를 띄워 두고 그 안에 진행 상황 — 기존 컴포넌트를 재사용할 수 있어
- (다) 작은 창을 따로 띄움 — 정보는 제일 많지만 화면을 가려

참고로 **처음 쓰는 사람은 여기서 547MB 모델을 내려받아.** 그때는 몇 분이 걸리고
진행률(%)과 남은 용량을 보여 줘야 해. 같은 화면에서 처리할지 따로 둘지도 같이 정해 줘.

### 2-2. 결과 화면

지금은 Finder 로 파일만 보여 주고 끝나. **앱 안에서 읽고 고칠 화면**이 있으면 좋겠어.
기존 팝오버는 짧은 받아쓰기용이라 회의록을 담기엔 작아.

회의록은 이런 구조로 나와 (없는 항목은 빠져):

```
## 한 줄 요약
## 결정된 것
## 할 일          ← "할 일 — 담당자, 마감" 꼴. 말 안 한 건 안 붙어
## 논의한 것
## 다음에 볼 것
```

필요한 동작: 복사, 파일 위치 열기, 받아쓴 원문 보기, (가능하면) 고치기.

⚠️ **앞으로 화자 구분이 들어갈 자리를 미리 비워 둬.** 지금은 "누가 말했는지"가 없는데,
나중에 `화자 1`, `화자 2` 로 나뉘어 나오고 **사용자가 거기에 이름을 붙이는** 흐름이 생겨.
그때 화면을 갈아엎지 않도록 자리를 잡아 줘.

## 3. 설치 마법사에 추가할 내용

`Brefly Onboarding.dc.html` 에 두 가지 설명을 넣어야 해.
지금 단계는 이래: 환영 → 마이크 → 음성 인식 → AI 모델 → 단축키 → 붙여넣기 → 사용 분야 → 완료

- **핵심 요약** — 말한 걸 그대로 다듬는 것 말고 **요점만 뽑아 주는** 모드가 있다는 것.
  어디서 켜는지도.
- **회의록** — 녹음 파일을 넣으면 회의록을 만들어 준다는 것.
  **녹음이 기기 밖으로 나가지 않는다**는 점을 꼭 넣어 줘. 회의 내용이라 사람들이 제일 걱정해.
  다만 요약할 때만 클라우드를 쓴다는 것도 숨기지 말고 같이 적어 줘.

단계를 새로 추가할지, 기존 단계 안에 넣을지는 네가 판단해 줘.
**설치 마법사가 이미 길다**는 게 문제야 — 단계가 늘면 도중에 그만두는 사람이 생겨.
텍스트도 이미 한 번 줄인 적 있어.

## 지켜야 할 것

- **팔레트** (코드의 `Theme.swift` 값 그대로)
  - 코랄: `#e0604a` (녹음 중), 진한 `#c2452f`, 밝은 `#ff6b52`
  - 밝은 모드 면: `#f2f3f5`, 선: `#eceef1`, 진한 선: `#dcdfe4`
  - 어두운 모드: 패널 `#1d2026`, 카드 `#2a2d35`, 선 `#3a3e47`,
    흐린 글자 `#565b66`, 글자 `#cdd1d8`, 보조 글자 `#9ba0a9`
- **밝은 모드와 어두운 모드를 둘 다** 그려 줘. 실제로 둘 다 지원해.
- **메뉴바 팝오버는 작아.** 기존 시안 크기를 넘지 않게 해 줘.
- 모든 문구는 **한국어**, 설정·안내 문구는 **'~합니다'체**.
- **전문 용어를 쓰지 마.** 비개발자가 읽어 (예: "백엔드" 대신 "AI 모델").
- 어두운 모드에서 대비를 꼭 확인해 줘. 전에 밝은 회색 칩이 어두운 배경에서 안 보인 적 있어.

## 정리하면

1. 지난 시안 이후 바뀐 것들(핵심 요약 등)을 반영해서 확인받기
2. **회의록 처리 중 화면** — 세 방향 그려 주고 추천
3. 회의록 결과 화면 (화자 이름 붙일 자리 포함)
4. 설치 마법사에 핵심 요약·회의록 설명 넣기

2번이 제일 급해. 없으면 기능이 멈춘 것처럼 보여서 사람들이 중간에 포기해.
